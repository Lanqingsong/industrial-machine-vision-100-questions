# 关于这本书

这本书面向想学习工业视觉、准备相关面试，或需要参与视觉项目的读者，内容从相机、镜头、光源等硬件选型讲起，延伸到算法、PLC 通信和系统集成。每个问题都配有示意图、公式或代码，方便把单个器件和参数放回完整的视觉系统中理解，也方便按问题查找和复习。当前公开 Q1–Q50；完整版本通过 README 中的二维码进入。

## 全书结构

- **第一部分：相机、镜头与成像硬件选型（Q1–Q31）**
  
  相机参数、镜头、景深、远心、光源、三维成像和硬件选型。

- **第二部分：算法基础（Q32–Q40）**
  
  标定、模板匹配、Blob、OCR、MTF、异常检测、三维视觉和项目验收。

- **第三部分：PLC 通信、实时控制与系统集成（Q41–Q70）**
  
  触发、I/O、工业通信、编码器、运动控制、HMI、环境因素和黄金样本。

- **第四部分：算法工程、软件架构与项目交付（Q71–Q100）**
  
  数据、稳定性、模型部署、版本管理、权限、成本、边缘设备、多线程和日志。

当前仓库提供 Q1–Q50 的 Markdown 正文和配图；Q51–Q100 不在本次公开内容中。

当前发布的 Markdown 文件按阅读和装配需要拆分为三个文件：第一章 Q1–Q30，第二章 Q31–Q40，第三章 Q41–Q50。这里的文件拆分服务于本次阶段性发布，不改变上面的全书部分结构。
