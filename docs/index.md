# 工业与机器视觉100问

这本书面向想学习工业视觉、准备相关面试，或需要参与视觉项目的读者，内容从相机、镜头、光源等硬件选型讲起，延伸到算法、PLC 通信和系统集成。每个问题都配有示意图、公式或代码，方便把单个器件和参数放回完整的视觉系统中理解，也方便按问题查找和复习。目前先发布 Q1–Q50，后续章节会继续补全。
